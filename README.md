## Part 1: Retaining Walls

### Wall Types

| Type | Materials | Typical Use |
|---|---|---|
| Rock wall | Sandstone, bluestone, Wee Jasper stone | Structural and feature walls |
| Garden wall | Dry-stacked blocks, face blocks, stone, sleepers | Small decorative walls |
| Block wall | Concrete blocks on concrete footing | Retaining soil or earth |
| Sleeper wall | Concrete posts and sleepers | Practical retaining on slopes |

| Wall Height | Footing |

## Part 7: Failure Modes and Prevention

| Failure | Typical Cause | Prevention |
|---|---|---|
| Leaning wall | No drainage, light footing | Aggregate, weep holes, agi line, footing by height |
| Sinking driveway | Thin pavers, poor base | ≥ 80mm pavers on compacted base |
| Pooling water | Wrong falls | Accurate levelling during excavation |
| Gate not latching | Posts moved with soil | Correct post footings, fence after walls |
